# 결제 및 이벤트 연동 시스템 개발 보고서

## 1. 결제 확인
- **결제 게이트웨이 통합**:  
  - 트랜잭션 처리를 위한 결제 게이트웨이 통합 및 결제 금액 확인 기능 구현
- **결제 완료 후 트리거**:  
  - 결제가 성공적으로 완료되면, 지불 금액에 따라 발급할 쿠폰 또는 티켓 수량을 계산하는 함수를 실행  
  - 예시: 최종 결제 금액 10/20/30/40 등에 따라 각각 상응하는 쿠폰을 지급

## 2. 쿠폰/티켓 발급
- **티켓 발급 처리**:  
  - 결제 완료 후 계산된 티켓 수량을 사용자의 계정에 발급  
- **데이터 관리**:  
  - 사용자 ID, 발급된 티켓 수량, 발급 날짜 등 티켓 관련 정보를 MongoDB에 저장  
  - 발급된 티켓은 슬롯 머신 이벤트 참여에 사용될 예정

## 3. 팝업 알림 기능
- **이벤트 알림 제공**:  
  - 배너 및 팝업을 통해 이벤트 페이지 진입 시, 현재 본인의 티켓 수량과 도전 회수를 확인할 수 있도록 알림 전달

## 4. 슬롯 머신 이벤트 연동
- **티켓 연동 및 사용 관리**:  
  - 발급된 티켓을 룰렛 이벤트와 연동하여 사용자가 이벤트 참여 시, MongoDB에 저장된 티켓 데이터를 불러와 사용 가능 여부 확인  
  - 티켓 사용 시, 데이터베이스에서 사용 내역을 업데이트하여 남은 티켓 수량 관리
- **중복 참여 및 당첨 확률 상승 로직**:  
  - 티켓 수량에 따른 중복 참여가 가능하도록 설정  
  - 재참여 시 당첨 확률을 0.05%씩 증가시켜, 티켓 수량에 따른 당첨 확률을 높이는 로직 추가

## 5. 확률 데이터 관리
- **경품 당첨 확률 설정**:  
  - 슬롯 머신 이벤트 내 각 경품에 대한 당첨 확률을 설정  
  - 관리자가 직접 확률을 조정할 수 있도록 인터페이스 제공
- **재도전 로직**:  
  - 재도전 시 당첨 확률을 0.05% 증가시키는 로직을 추가하여 사용자가 보유한 티켓 수에 따른 당첨 확률을 개선
